## Project Overview

This project analyzes 14 days of sales and stock records for Wanjiku's fresh-produce stall at Gikomba Market. It evaluates sales performance, weekly growth, trading-day patterns, stock levels, and product profitability using core Python. The analysis provides practical recommendations to improve inventory management and business performance.

## How to Run

Open the analysis notebook in Google Colab: [Open in Colab](https://colab.research.google.com/github/YOUR_GITHUB_USERNAME/plp-da-a1-gikomba-stall-analysis/blob/main/stall_analysis.ipynb)

## Top Three Findings

1. **Total Sales:** KES 44,850 across 14 days, with average daily sales of KES 3,203.57.
2. **Weekend Performance:** Average weekend sales were KES 4,900, which is 78.18% higher than weekday sales.
3. **Stock and Profitability:** Tomatoes and sukuma require restocking. Avocado recorded the highest gross margin at 42.86%.
